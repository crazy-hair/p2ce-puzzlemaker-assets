This repository contains an asset pack for MinerKid's P2:CE puzzlemaker that add several Portal 1-themed elements, as well as general useful entities such as portal placement helpers and cubemaps. 
Everything under the `P1 Enhanced` category requires my [Portal 1 PBR Pack](https://steamcommunity.com/sharedfiles/filedetails/?id=3706931664) to be subscribed to *and enabled in the Hammer addon manager* to work.
Certain instances like the recessed lighting and piston pit require my `lights.rad` file. Unfortunately there's no way to have multiple lights.rad files installed at a time, so I would recommend throwing it in your custom folder only when you need to compile P1 Enhanced maps, and remove it when you're compiling stock P2 maps.
